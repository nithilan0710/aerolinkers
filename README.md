# AeroLinkers

AeroLinkers is a product that integrates hardware design, firmware development, and backend software into a unified platform for wireless/wired airport assistance application.

## Repository Structure

```
aerolinkers/
├── software-dev/       # Backend server code and system block diagrams
├── hardware-dev/       # Schematics, PCB, Gerbers, and datasheets
├── embedded-dev/       # Firmware libraries, headers, config, and device overlays
└── Documents/          # Project documentation
```

## Modules

- **software-dev** — Backend server handling device communication and data APIs, along with system-level block diagrams.
- **hardware-dev** — Circuit schematics, PCB layout, fabrication Gerbers, component datasheets, and hardware block diagrams.
- **embedded-dev** — Embedded firmware including driver libraries, header files, build configuration, and device tree overlays.

# Hardware Development

Contains all hardware design files for AeroLinkers.

## Contents

- **schematics/** — Circuit schematics (KiCad / EasyEDA)
- **pcb/** — PCB layout files and BOM
- **gerbers/** — Fabrication-ready Gerber files
- **datasheets/** — Component datasheets organized by type
- **block-diagrams/** — Hardware block diagrams and power architecture
